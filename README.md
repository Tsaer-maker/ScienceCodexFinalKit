# ScienceCodexFinalKit

No-Claude-account Windows/WSL workbench for native Linux Claude Code with DeepSeek, Kimi, GLM, ChatGPT/Codex, and an isolated Windows Chrome bridge.

- [中文 README](README.zh-CN.md)
- [从零安装与日常操作](operation.md)
- [代码与安全边界剖析](docs/CODE_WALKTHROUGH.zh-CN.md)

Run `SwitchModel.cmd`. Use menu `7–10` for Claude Code plus the browser bridge, or `19–22` for Claude Code only. Claude/Claude.ai accounts are not used by the default workflow.
